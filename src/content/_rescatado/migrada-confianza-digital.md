# Confianza Digital. Cinco formas de acceder.
Servicios eIDAS cualificados — firma, sello, entrega, custodia, certificados — accesibles como API, plataforma enterprise, app móvil o servicios QTSP directos. Diseñados por Garrigues, operados por EADTrust .
· link: Evaluar servicios

## Cinco tipologías de producto
Desde la infraestructura API hasta la app de bolsillo, cada tipología ofrece un nivel diferente de acceso a los mismos servicios eIDAS cualificados.

### La Factoría (Trust API)
Para empresas con equipo técnico que quieren inyectar servicios eIDAS en sus propios sistemas vía API REST
4 microservicios eIDAS como primitivas REST: Evidence (timestamps), Signature (AES/QES), Notification (ERDS), Custody (archivo). ~45ms latencia. JSON nativo. SDKs en TypeScript, Java, Python, .NET.
· link: Descubrir Trust API

### EAD Enterprise Suite
Para grandes organizaciones que necesitan una plataforma unificada de servicios eIDAS con soberanía digital
Plataforma que hoy agrega Signature Manager, Notice Manager, eArchiving y Credential Manager. Seguirá creciendo incorporando chat certificado, archivo cualificado (arts. 45i-45j), EUDI Wallet y más servicios eIDAS. Oracle EU Sovereign Cloud.
· link: Descubrir Enterprise Suite

### Soluciones diseñadas por g-digital
Productos individuales con UX empresarial, disponibles de forma independiente o como parte de Enterprise Suite
Cada producto está diseñado por g-digital (abogados + tecnólogos de Garrigues) y operado comercialmente por EADTrust. Pueden contratarse individualmente o como parte de la Suite.
Signature Manager
Orquestación de firma con validador legal, verificación SHA-256, firma vía WhatsApp
Notice Manager
Notificaciones certificadas multicanal (email, WhatsApp, SMS, RCS). Sustituye al burofax
eArchiving
Custodia con garantía LTV, re-sellado periódico, preparado para arts. 45i-45j eIDAS 2
Credential Manager
Certificados cualificados en Cloud HSM. Delegación segura. EUDI Wallet Ready
Comercialización y soporte: eadtrust.eu

### GoCertius
Para profesionales y PYMEs que necesitan servicios de confianza sin integración técnica
SuperApp que hoy agrega certificación de hechos, sello de tiempo cualificado, Chat Certificado (Telegram) y multimedia certificada. Como Enterprise Suite, es una plataforma evolutiva que irá incorporando más servicios eIDAS. +40.000 evidencias (2025-2026).
· link: Visitar gocertius.io

## Plataformas evolutivas para eIDAS 2.0
Enterprise Suite y GoCertius son suites que incorporarán automáticamente los nuevos servicios eIDAS 2.0 conforme se publiquen los actos delegados.

### Nuevos servicios eIDAS 2.0
- Archivo Electrónico Cualificado Arts. 45i-45j. Presunción de integridad y origen.
- EUDI Wallet Cartera digital europea. Interoperabilidad nativa.
- QEA/QEAA Attestations Atestaciones cualificadas de atributos.
- QSCD Cloud Firma cualificada en nube con autenticación fuerte.

### Suites que crecen contigo
